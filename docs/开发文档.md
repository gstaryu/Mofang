# 墨仿 Mofang 开发文档

## 一、项目结构

```
Mofang/
├── core/                    # 共享核心引擎（无 UI 依赖，网页版/桌面版/测试脚本共用）
│   ├── template.py          # PaperTemplate / WritingArea / PageGeometry（含 row_lines 行基线）
│   ├── font_loader.py       # FontAsset / FontLibrary：字体加载、cmap 覆盖检测、备用字体
│   ├── layout.py            # LayoutEngine：半格粒度分词、避头尾禁则、断行、分页
│   ├── render.py            # RenderParams / HandwritingRenderer：手写感渲染（逐行自适应）
│   ├── exporter.py          # export_png / export_pdf（img2pdf，物理尺寸精确）
│   ├── preset.py            # PresetManager：预设 JSON 持久化（双端通用）
│   ├── detect.py            # 视觉定位：投影剖面法检测横线与书写区边界（numpy，<0.5s）
│   ├── region.py            # grid_from_corners：四角点选 → 格网换算（手动兜底）
│   └── pipeline.py          # generate_pages：端到端流水线（校验→排版→渲染）
├── server/
│   ├── app.py               # FastAPI 薄外壳：REST API + 静态资源
│   └── web/                 # 前端（原生 HTML/CSS/JS，无构建步骤）
│       ├── index.html
│       ├── style.css        # 纸墨设计系统（CSS 变量 token）
│       └── app.js
├── desktop/
│   └── main.py              # 桌面版薄壳：pywebview 原生窗口内嵌网页版前端（UI/功能 100% 一致）
├── data/                    # 运行时数据
│   ├── templates/           # 模板图片 + {id}.json 注册表
│   ├── fonts/               # 用户字体库
│   ├── presets/             # 预设 JSON（双端通用）
│   └── output/              # 导出/测试输出
├── docs/                    # 用户文档 / 开发文档 / API 文档 / 截图
├── tests/                   # 冒烟测试（test_phase1.py 等）
├── start.bat                # 一键启动网页版（自动建环境/装依赖）
├── 桌面版.bat                # 启动桌面版
└── requirements.txt
```

## 二、技术栈与依赖

| 层 | 技术 | 用途 |
|---|---|---|
| 渲染 | Pillow | TTF 光栅化、逐字瓦片旋转合成、PNG 输出 |
| 字体解析 | fontTools | 读 cmap 计算字符覆盖集（缺字检测） |
| PDF | img2pdf（底层 pikepdf） | 无损嵌入 PNG、强制页面物理尺寸 |
| Web | FastAPI + uvicorn | REST API、静态文件、自动 OpenAPI 文档 |
| 前端 | 原生 HTML/CSS/JS | 零构建；Canvas 四角标注；FontFace 动态字体预览 |
| 桌面 | pywebview（WebView2） | 原生窗口内嵌网页版前端；进程内 uvicorn |
| 打包 | PyInstaller | 桌面版单目录 exe |
| 环境 | conda `mofang` (Python 3.11) | 见 requirements.txt |

## 三、核心设计要点

- **坐标系**：模板内部一律用原图像素坐标；`PageGeometry` 保存物理 mm 尺寸，DPI = 像素/物理，导出 PDF 时换算 `pt = mm/25.4*72` 强制页面尺寸 → 打印“实际大小”即对齐。
- **排版**：`LayoutEngine` 以**半格**为最小单位（全角 2 半格、半角字母/空格 1 半格、`——`/`……` 4 半格），URL 等超长串按整行硬切；排版时先换行再判禁则（顺序不能反），行首禁则标点以 `squeezed` 标记挤入上一行末格（渲染时缩至 55% 画在右下角）。
- **行定位**：`PaperTemplate.row_lines`（每行书写基线 y）是所有模板的统一表示——内置模板与用户上传均由 `core/detect.py` 投影检测生成（跳过页首线），手动四角为兜底（等距基线）。渲染时：第 r 行字底坐在 `row_lines[r]` 上，行高取真实局部行距 `row_lines[r]-row_lines[r-1]`，字号随之自适应；竖直抖动幅度受基线保护（不超过行内空隙），字不会压线/越线。
- **手写感**：`RenderParams` 每字独立 RNG（seed+页码 派生，可复现）：位移/旋转/字号/墨色 alpha 四维抖动 + 行基线低频正弦波 + `stroke_bold` 笔画加粗（PIL stroke_width 模拟按压出墨）；英文/数字**整词渲染**（实测宽度瓦片，自然字距，超宽才等比缩小）。
- **双端一致性**：所有业务逻辑在 `core`，桌面版为 pywebview 原生窗口内嵌同一套网页前端（进程内 uvicorn），UI/功能与网页版天然 100% 一致；预设 JSON 直接互通。
- **PyInstaller 打包**：frozen 模式下数据目录由 `core/paths.get_data_dir` 解析为 `exe旁/data`（首启从 `_MEIPASS/data` 复制；`MOFANG_DATA` 环境变量可覆盖）；未捕获异常写入 `data/mofang-error.log` 并弹窗。

## 四、本地开发运行

```bash
conda activate mofang
# 后端（改动 server/ 或 core/ 后重启）
python -m uvicorn server.app:app --port 8642 --reload
# 前端无需构建，刷新浏览器即可（静态文件实时生效）
# 桌面版
python desktop/main.py
# 冒烟测试
python tests/test_phase1.py
```

浏览器访问 `http://127.0.0.1:8642/docs` 可查看/调试 REST API。

## 五、打包和发布流程

### 桌面版 exe（PyInstaller）

```bash
conda activate mofang
pyinstaller --noconfirm --windowed --name Mofang ^
  --icon desktop/icon.ico ^
  --add-data "data;data" --add-data "server/web;server/web" --add-data "desktop/icon.ico;." ^
  --collect-all webview ^
  --add-binary "%CONDA_PREFIX%\Libraryin\libcrypto-3-x64.dll;." ^
  --add-binary "%CONDA_PREFIX%\Libraryin\libssl-3-x64.dll;." ^
  --hidden-import ssl desktop/main.py
# 产物在 dist/Mofang/（OpenSSL DLL 必须显式收入，否则启动报 _ssl 缺失；
# --windowed 下 sys.stdout 为 None，壳内已重定向到日志文件）
```

> 注意：`--add-data` 会把当前 data/（含模板与字体）打进包；发布前可精简 data/templates 与 data/fonts。
> exe 与源码版共用 data 目录的相对路径逻辑，解包后可直接使用。

### 源码发布

1. 打包 zip（排除 `data/output/`、`build/`、`dist/`）；
2. 接收方解压后双击 `start.bat`（需已装 Miniconda）。

## 六、代码约定

- `core/` 不允许 import 任何 UI / Web 框架；
- 新增渲染参数需两处同步：`core/render.py RenderParams`（含 validate）→ `server/web/index.html + app.js`（桌面版内嵌同一前端，自动继承）；
- 错误处理：core 层抛 `ValueError`（中文信息），server 层转 HTTPException(400)，desktop 层写 `data/mofang-error.log` 并弹系统对话框。
